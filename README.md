# Motion-score · 移动原声带

保留原来的 14 张设计图，增加可点击的手机网页、DeepSeek 歌单编排、高德路线与前台运动轨迹，以及本机原声带记录。

## 本地启动

需要 Python 3.10 或更新版本，后台仅使用 Python 标准库，无需安装第三方 Python 包。

1. 复制 `.env.example` 为 `.env`。
2. 填写自己的 `DEEPSEEK_API_KEY` 和高德 Web 服务密钥 `AMAP_WEB_SERVICE_KEY`。密钥只放在本机。
3. Windows 双击 `启动本地版.cmd`；其他系统在项目目录运行 `python launch.py`。
4. 使用启动器打开的地址访问 `mobile-app.html`，不要直接用 `file:///` 打开 HTML。

没有 DeepSeek 密钥时可以使用本地规则编排。高德地图、路线和真实轨迹的坐标转换需要高德配置及网络连接。

原设计图对照入口为 `motion-score-html.html`。完整操作与配置见 [本地检查说明](本地检查说明.md)，检查记录见 [检查结果](检查结果.md)。

## 已实现的流程

- 户外：选跑步或驾车 → 编辑地点 → 规划和选择路线 → 编排音乐 → 播放与记录轨迹 → 结束 → 保存到本机。
- 室内：选择运动与时长 → 编排音乐 → 播放 → 完成 → 保存。
- 固定首页、探索、记录和我的导航；记录可以打开、试听、收藏及复用。
- AI 编排失败时给出提示并使用本地规则；路线规划失败时提示修改地点或重试。

## 当前范围

- 歌曲是本项目合成的示例音频，QQ 音乐账号与真实曲库尚未接入。
- 分享、发现和保存仅在本机完成，尚未实现联网社区及真实账号系统。
- 地图采用高德地图图片加路线叠加，支持缩放及聚焦，尚未支持拖动、双指缩放。
- 真实定位要求安全访问地址和定位授权；本版本只支持前台记录，尚未实测手机 GPS 或锁屏持续记录。
- 原图没有改画；原图中的部分装饰文字、天气和运动指标仍为示例内容。
